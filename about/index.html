渐入佳境 | 一切都会慢慢变好

2024-04-25 更新

这几天都在给博客搬家，搬家的原因有很多：一是原来的服务器是随便买的，随着内容的变多，服务器的内存和存储都快耗尽了；二是之前的 justnews 主题功能较简单，很多插件不完善且需付费额外购买。随着橙子做的内容越来越多，更希望有个上限更高的平台来承载，所以斥巨资购买了正版的 7b2 主题和极 (子) 主题，只为能够输出更加精致的内容。

相信很多小伙伴都是通过 NAS 论坛来到这里的，由于官方的问题，不让再分享一些影视或其他资源，所以希望依靠本站的圈子（社区），给大家提供一个更加轻松的平台。同时博客也改了名字，和我用了多年的网名一样，希望一切都慢慢好起来 —— 工作、学习、事业、家庭、爱情、友情等等，慢慢渐入佳境。也希望在这里，能够让你获取片刻心里的宁静～

1. 基地介绍

你好新朋友，欢迎你来到这一页！

本站主要分享内容

  • NAS 折腾日记、服务器折腾不完全指南

  • 不定期分享好玩的东西：Docker 自建项目、博客搭建、早安推送、网站源码等

  • VPS、NAS 实测体验（避坑指南）

  • 高效工具推荐：好用的网站、在线工具等

总之，本站就是将我之前尝试过的东西分享出来，循着我这点光，点亮你自己的灵感～

平时工作比较忙的时候，更新会慢一些。有任何问题，都可以通过留言、微信、QQ、邮件联系到我。

大橙子的由来

在大学时期，我玩过一款质量很高的网游《龙之谷》。那时候喜欢喝柳橙味的奶茶，于是第一个角色（冰灵）就叫了 “柳橙”。

随着时间推移，《龙之谷》开始走下坡路，我接触到了第二款网游 —— 鼎鼎大名的《剑灵》。从极致封测、灵动内测，一直玩到浊魔版本，期间自己创立了门派，有很多一起玩的朋友。ID 依然是 “柳橙”，因为是门主，大家叫多了就变成了 “大橙子”。

这个 ID 一直用到了今天，它怀念的不光是曾经一起玩过的游戏、一起游玩的人，更是对曾经回不去的青春时光的一种缅怀～

2. 橙子的心愿

1. 希望自己产出的东西是真正有用的

一个人对某个事物感兴趣并去折腾时，难免会遇到各种各样的问题 —— 有自己研究解决的，也有跟着大佬教程一步步搭建的。但有时就是会遇到一些教程里没有提到的问题，百度搜索得到的都是千篇一律的 “废话文学”，毫无实际意义。这种阶段其实是很痛苦的，比如 NAS 影音库的折腾、VPS 上各种服务的搭建。

所以我会将自己接触过的东西，以流程化、细节化的方式输出出来，起码让大家按照步骤去实现时，不会遇到太大的问题。如果遇到一些我没有遇到过的问题，也可以发出来一起交流解决。

2. 希望大家能够学会独立解决问题的能力

有再多的教程和心得，都比不上自身的强大。所以遇到问题首先得靠自己 —— 百度、贴吧、论坛、GitHub 等各种你能想到的渠道，先去摸索、去寻踪。

在这个过程中，如果你能自己解决问题，这段经历会让你刻骨铭心，它会成为你未来输出 “解决问题心得” 的素材。当实在无望时，再求助别人、求助橙子，这时候你对问题才会有更深刻的理解和认知。

3. 希望大家学会感恩，忘记白嫖

基地分享的项目，很多都是 GitHub 上的开源项目。感谢开源，让我们可以免费使用、搭建自己喜欢的东西。

但你要知道，做任何事情都是要付出的 —— 可能是时间，可能是金钱。

  • 一些大的开源项目，往往会有免费的社区版和付费的商业版，也会放出捐赠渠道，来覆盖开发中产生的费用，以便项目能够正常维护下去。

  • 一些小的开源项目，没有付费版本，完全免费给大家使用。虽然也会放出诸如 “Buy me a coffee” 的捐赠打赏码，但据观察，国外项目还好，国内项目放到 GitHub 上，即使项目很不错，也很少有人捐助。

很多好的开源项目到后来就不维护了，为什么？大概率是作者也要为生活奔波，没有精力继续维护了吧。

说了这么多，不是让大家都去捐钱支持开源项目。我们也可以用其他方式支持：

  • 最简单的：给项目点个 Star，鼓励作者、认可项目。

  • 分享推荐：比如你觉得 WordPress 好用，就出一期教程分享，吸引更多人使用，这也是一种变相支持。

  • 反馈问题：使用中遇到 Bug 或建议，在 GitHub 提 Issues，帮助作者测试优化。

  • 参与开发：如果你是开发者，可以加入项目，贡献自己的代码，让项目变得更强。

这才是开源项目健康发展的关键 —— 而不是只知道索取，下载了代码就自己用，甚至不点一个 Star。

回到微光基地，也是一个道理：看了教程觉得内容不错的，该点赞就点赞，该留言就留言，该互动就互动。如果真的有用，解决了困扰你已久的问题，也可以请橙子喝杯咖啡，这样才能保证我能够源源不断地分享自己的经验。

学会感恩，忘记白嫖，哪怕只是动动小手，受益的其实还是自己。
